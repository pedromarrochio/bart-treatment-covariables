# Dengue Prediction Model (BART)

A dengue case forecasting model developed by **Jo De Nápoles**, built using **BART (Bayesian Additive Regression Trees)** and treatment-related covariates. The project adapts and expands upon the `forecast-dengue` framework.

## Features
- Robust dengue outbreak forecasting using Bayesian Additive Regression Trees.
- Integration of treatment-related covariates.
